# Backtesting Terminal

By Chroma Financial. This is where Backtesting Terminal's installers and updates are published. Download the latest version from [Releases](https://github.com/TylarKapoor/chroma-backtesting-terminal-releases/releases/latest).

- **Windows:** `Backtesting-Terminal-Setup-<version>.exe`
- **macOS** (Apple silicon): `Backtesting-Terminal-<version>-macos.dmg`

Installed copies check here for updates by themselves. Versions before 0.14 were called Backtester and are still listed under that name.
